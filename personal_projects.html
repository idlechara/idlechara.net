raton: It's the source code of the last robot that I used at UTFSM Robotics Contest (2014). It has a implementation of a cooperating ARM-AVR processors working together to solve cycled laberinths by using a graph implementaion of flood-fill. Why did I used two processors? Because I wanted one to be in charge of solving the maze (Teensy ARM) while the other (AVR ATMEGA328p) traverses it using the info provided by the solver.
LSM303DLHC: At the previous Robotics Contest that I attended, both I and a friend were trying to experiment with accelerometers and magnetometers to handle orientation for "Leela", a multipropouse robot that he made using a PS3 Eye. Well, that's the library used on a BeagleBone to test if that was possible to accomplish in order to win the competition (in the end we used a mouse to track the movements xD).
